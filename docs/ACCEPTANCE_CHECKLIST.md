# StuKit UI-5 人工验收清单

## 1. 验收规则

本清单用于确认真实窗口和真机中的视觉、触摸、输入法与数据持久化。自动测试通过只能
证明布局属性和业务结果符合预期，不能替代以下人工检查。

- 使用 Debug 测试数据，不要在验收过程中恢复或覆盖个人正式数据库。
- 每完成一项，把 `[ ]` 改为 `[x]`；未通过时不要勾选，按文末格式记录问题。
- Windows 和 Android 必须分别验收。只在桌面缩小窗口不能代表 Android 真机通过。
- 验收期间不要提交 APK、数据库、签名文件或 `build/` 目录。

## 2. Windows 尺寸与缩放矩阵

在 Qt Creator 中选择 `Desktop Qt 6.10.3 MSVC2022 64bit` Debug Kit，依次检查：

- [ ] 960 × 640：侧边导航完整，首页四个入口可见或可滚动，没有水平溢出。
- [ ] 1280 × 720：内容居中，卡片间距一致，主要操作和次要操作层级清楚。
- [ ] 1440 × 900：内容最大宽度生效，不会随窗口无限拉宽。
- [ ] 1920 × 1080、Windows 缩放 125%：文字、按钮和图表没有裁切。
- [ ] 1920 × 1080、Windows 缩放 150%：输入框标签和中文说明可以完整换行。
- [ ] 从宽窗口连续缩到 720 px 附近：导航切换时当前模块不丢失、不闪退。

每个尺寸都要快速进入首页、记账、课表和待办，确认页面能够滚动到底部且没有
控件越过窗口左右边缘。

## 3. Android 尺寸与系统区域

使用 `Android Qt 6.10.3 Clang arm64-v8a` Debug Kit 安装到 ARM64 真机：

- [ ] 约 360 × 800 dp 竖屏：首页使用底部导航，三个公开模块都能进入。
- [ ] 约 412 × 915 dp 竖屏：卡片宽度、左右边距和文字换行自然。
- [ ] 800 × 360 dp 横屏：仍使用紧凑导航，刘海与左右手势区不遮挡内容。
- [ ] 状态栏、底部手势条和圆角区域没有覆盖标题、按钮或最后一行内容。
- [ ] 竖屏与横屏往返一次后，仍停留在原模块，数据和筛选状态没有意外重置。
- [ ] Android 系统字体分别设为默认、较大和最大可接受档，核心按钮文字仍可理解。

## 4. 返回键与软键盘

在记账、课表和待办中各打开一个包含多项输入的编辑弹窗：

- [ ] 点击靠近表单底部的输入框，软键盘弹出后输入框会滚动到可见区域。
- [ ] 键盘弹出时第一次按系统返回键只收起键盘，不关闭弹窗。
- [ ] 键盘收起后再次按返回键关闭弹窗，不保存未确认的内容。
- [ ] 从数据分析页按返回键回到记账本。
- [ ] 从记账、课表或待办按返回键回到首页。
- [ ] 在首页按返回键由 Android 正常退出或进入系统后台，不出现空白页面。

## 5. 记账

- [ ] 首页统计、账户余额和流水列表显示正常；数据工具默认折叠。
- [ ] 新增、编辑和删除一条测试流水正常。
- [ ] 账户与分类编辑弹窗不超过窗口，底部操作按钮始终可到达。
- [ ] 点击“数据分析”进入共享分析页，月份、账户、分类和图表切换正常。
- [ ] 环形图、趋势图和排行在窄屏没有横向裁切，页面滚动不与图表手势冲突。
- [ ] 数据库备份、恢复和 CSV 导出只操作测试数据，并能正确处理 Android 文件选择器。

## 6. 课表

- [ ] 查看模式显示网格课表；窄屏可以切换按天视图并查看完整课程信息。
- [ ] 进入编辑模式后，格子按压反馈明显，点击格子能选择课程并批量设置周次。
- [ ] 编辑模式可以切换上一周、下一周，课程显示与当前周一致。
- [ ] 增加一节和减少一节只在编辑模式出现，节次时间编辑清楚且可滚动。
- [ ] 学期、课程资料、期末考核和教学安排均可编辑；弹窗不被键盘遮挡。
- [ ] CSV 导入成功和错误提示均清楚，不会产生重复或越界课程。

## 7. 天气

当前发布版本隐藏天气入口，本节暂不纳入发布阻断项；重新启用天气功能时恢复验收。

- [ ] 搜索城市、选择结果、刷新天气正常。
- [ ] 当前天气和七日预报卡片在窄屏纵向排列，没有文字重叠。
- [ ] 断网后能够显示缓存数据和明确提示；恢复网络后可以重新刷新。
- [ ] 搜索无结果和网络错误状态都有可理解的说明与重试入口。

## 8. 待办

- [ ] 页面标题只使用“待办”，新增任务是首要操作，窄屏筛选默认折叠。
- [ ] 默认分类包含作业、考试、竞赛；新增“社团”后任务编辑器可以选择。
- [ ] 截止时间和提醒时间使用滚轮选择；提醒晚于截止时拒绝保存。
- [ ] 任务可绑定课程；创建、编辑、完成、重新打开、归档、恢复和删除均正常。
- [ ] 重启应用后任务、自定义分类、归档状态和课程绑定仍存在。

## 9. 验收通过条件

同时满足以下条件才可结束 UI-5：

- [x] Qt 6.10.3 MSVC Debug 完整构建通过。
- [x] 60/60 自动测试通过。
- [x] Windows 应用启动冒烟通过，5 秒内无标准输出或错误输出。
- [x] Android arm64-v8a Debug APK 成功生成。
- [ ] Windows 尺寸与缩放矩阵全部通过。
- [ ] Android 真机、软键盘、旋转和返回键全部通过。
- [ ] 各业务模块核心流程全部通过，或已记录并修复阻塞问题。

## 10. 问题记录模板

发现问题时记录以下内容，不要只写“界面不好看”：

```text
平台与设备：Windows/Android，设备型号或缩放比例
窗口或屏幕：例如 960 × 640、360 × 800 dp
模块与页面：例如 待办 > 新建任务
复现步骤：1. ... 2. ... 3. ...
实际结果：哪个控件被遮挡、越界、无反馈或数据错误
预期结果：希望看到的具体行为
截图或日志：如有请附上
```

全部未勾选项目完成后，请通知我继续处理验收中发现的问题；届时再将 UI-5 和 M9 标为
完成，并讨论下一个业务模块。
