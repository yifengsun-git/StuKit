# StuKit 当前版本人工验收清单

## 1. 启动与导航

- 程序正常启动，首页和侧边栏显示“待办”，没有“待办 / 作业”或独立“数据分析”。
- 首页可以进入记账本、课表、天气和待办。

## 2. 待办

- 打开待办，确认默认分类包含作业、考试、竞赛。
- 点击“新增分类”，添加“社团”，重新打开任务编辑器后可以选择“社团”。
- 新建待办时，截止时间和提醒时间通过滚轮选择，不需要输入固定格式。
- 提醒时间晚于截止时间时应拒绝保存；清除截止时间时提醒时间也被清除。
- 创建、编辑、完成、重新打开、归档、显示归档、恢复和删除均正常。
- 重启程序后任务和自定义分类仍存在。

## 3. 数据分析

- 首页和侧边栏没有独立数据分析入口。
- 从记账本点击“数据分析”进入图表页面。
- 月份范围、账户/分类筛选和图表切换正常。
- 点击“返回记账本”回到原记账页面。

## 4. 回归检查

- 记账新增、编辑和删除流水正常。
- 课表查看与编辑正常。
- 天气页面可以打开；网络正常时可以搜索和刷新天气。

全部项目通过后，本轮功能验收完成；发现问题时记录所在模块、操作步骤和界面提示。
