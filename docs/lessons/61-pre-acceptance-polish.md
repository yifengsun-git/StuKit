# 第六十一课：验收前产品收口

## 本课目标

根据实际使用反馈统一产品命名、解除待办分类限制、改善时间输入，并把共享数据分析
能力放回当前的数据来源模块中。

## 完成内容

- 所有一级入口统一显示“待办”，不再显示“待办 / 作业”。
- SQLite schema 10 新增 `task_categories` 和任务分类名称，原有作业、考试、竞赛数据会
  自动迁移，用户可以新增社团、实习等自定义分类。
- 截止时间和提醒时间改用年、月、日、时、分滚轮选择；仍由 Presentation 转成 UTC，
  数据库格式和提醒规则不变。
- 数据分析不再占用首页和侧边栏的一级入口。记账本内增加“数据分析”按钮，分析页提供
  “返回记账本”，共享图表模型和组件仍位于独立 `features/analytics` 模块。
- 自动测试新增自定义分类持久化、滚轮时间值和分析返回交互覆盖。

## 架构说明

“共享模块”不等于“必须出现在主导航”。分析模块负责通用图表数据模型和可复用组件，
记账模块负责提供收入、支出、账户和分类数据。以后饮食或学习模块需要分析时，可以复用
相同图表组件并提供自己的数据 ViewModel，而不必复制记账页面。
