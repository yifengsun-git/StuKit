# 第四十一课：查看模式与学期排课编辑模式

## 本课结果

课表已经拆分为两个含义明确的模式：

- 查看模式显示某个教学周实际发生的课程。
- 编辑模式显示整个学期的排课模板。

进入“编辑课表”后，用户先选择一门课程，再点击空白节次添加安排；点击已有课程块
可以修改安排。新增安排默认应用到整个学期，也可以限制起止周，并选择每周、单周或
双周。保存仍经过 Application 层冲突检测，不允许 QML 直接写 Repository。

## 1. 为什么需要两个模型

查看模式必须遵守当前教学周和单双周过滤，例如第 2 周不显示单周课程。编辑模式不能
使用这份过滤结果，否则单周课程在双周会消失，用户无法编辑。

因此现在有两份表现模型：

```text
ScheduleViewModel.meetings
  当前所选教学周实际发生的课程

ScheduleManagementViewModel.termSchedule
  所选学期的全部课程安排
```

两者都使用 `WeeklyScheduleListModel` 的统一角色，因此复用同一个 `WeeklyGrid.qml`，
但数据语义不会混淆。

## 2. 学期排课模型

`WeeklyScheduleItem` 和 `WeeklyScheduleListModel` 新增：

```text
startWeek, endWeek, weekPattern, weekRangeText
```

`weekRangeText` 会生成“第 1～18 周 · 每周”等可读文本。管理 ViewModel 将当前学期
所有 Course 和 CourseMeeting 组合成网格项目，并按星期、节次、课程名稳定排序。

## 3. 网格编辑流程

`ScheduleGridEditor.qml` 完成以下流程：

1. 从当前学期课程中选择要排入的课程。
2. 点击空白网格，自动带入星期和起始节次。
3. 结束节次默认是下一节。
4. 起止周默认覆盖整个学期。
5. 可切换每周、单周或双周。
6. 保存成功后自动刷新学期模板和实际周课表。
7. 保存冲突时保留编辑窗口并显示冲突课程与首次冲突周。

点击已有课程块会带入原 UUID、课程、星期、节次、周次和单双周规则，因此是更新同一
条安排，不会误创建重复数据。

## 4. 课程资料与排课分离

原“学期与课程管理”弹窗改为“学期与课程资料”，只负责：

- 学期创建、编辑、归档和恢复。
- 课程名称、教师、教室和颜色。

上课安排不再作为第三层列表放在资料弹窗中，统一回到可视化网格编辑器。这样用户先
定义“这是什么课程”，再决定“它在什么时候上课”。

## 5. 当前批量能力

本课沿用现有稳定领域模型，支持：

- 整个学期每周重复。
- 指定起止周每周重复。
- 指定范围内只在单周重复。
- 指定范围内只在双周重复。

任意离散周次，例如只选择第 1、2、5、8 周，需要新的持久化结构，本课没有仓促修改
数据库。该能力进入下一课。

## 6. 自动测试

测试新增验证：

- 当前周模型保留起止周和单双周角色。
- 管理 ViewModel 能提供整个学期的排课模型。
- 第 2 周查看模式只显示实际发生的两条课程。
- 编辑模式显示学期内全部三条安排，包括当前周不发生的单周课程。
- 点击空白格后默认节次来自点击位置，默认周次为第 1～18 周。
- ViewModel 重绑定后不会继续显示旧对象数据。
