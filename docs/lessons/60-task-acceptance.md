# 第六十课：待办模块集成验收

## 本课目标

验证待办模块不只是各层分别可用，而是能从 QML、Presentation、Application 一直工作
到 SQLite，并在应用重启后保留正确状态。

## 完成内容

- 组合根集成测试覆盖创建任务、完成任务、完成率更新、应用重启恢复、归档和查看归档。
- QML 集成测试覆盖空状态、创建后列表刷新、统计区两列/四列响应式布局，以及应用内
  提醒的显示和关闭。
- 主清单按已逾期、今天、未来 7 天、更晚、无截止时间、已完成和已归档显示分组标题，
  保留截止时间优先、优先级次之的稳定排序。
- 构建和 `all_qmllint` 检查通过，没有新增 QML 静态警告。
- 任务 Domain、Application、SQLite Repository、组合根和 QML 测试共同覆盖核心链路。

## 当前功能边界

待办 MVP 已支持创建、编辑、搜索、分类筛选、课程绑定、完成、重新打开、归档、恢复、
删除、逾期统计、完成率和应用内提醒。所有时间在数据库中保存为 UTC，界面按用户时区
显示。

当前提醒属于“应用内提醒”，程序关闭时不会由操作系统唤醒。Windows 通知中心与
Android 后台通知属于后续平台适配工作，不需要修改任务领域模型和用例。

## 后续方向

待办 MVP 到这里形成了一个可以持续使用和扩展的整体。后续可选择继续增强日期时间
选择器、任务分组和系统通知，或开始下一个独立功能模块。
