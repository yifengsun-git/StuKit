# 第四十二课：课表节数、按钮反馈与课程资料

## 本课结果

本课先处理课表实际使用中发现的三个问题：课表不再固定显示 20 节；按钮按下时有
明确颜色反馈；课程资料可以记录期末考核标准和课程教学安排。

## 1. 可增加的课表节数

课表默认显示 12 节，顶部显示当前节数，并提供“− 减少一节”和“+ 增加一节”按钮。
每次点击调整一节，可在 1～20 节之间变化，与 `CourseMeeting` 的业务上限保持一致。

`ScheduleHomePage.schedulePeriodCount` 是查看网格和编辑网格共享的界面状态，因此切换
模式不会回到另一套节数。窄屏的按天列表不依赖网格高度，进入编辑模式后仍可调整。

这一设置目前只在本次运行期间保存。将来如果需要跨重启记忆，应通过设置服务持久化，
不把纯界面偏好写入课程数据库。

网格容器高度直接绑定已加载视图的 `implicitHeight`，因此首次进入课程主页便会显示
课表，不再依赖调整节数触发第二次布局。

## 2. 统一按钮反馈

新增 `AppButton.qml` 作为通用按钮外观。应用壳、记账、分析和课表模块中的普通按钮
统一使用它：

- 普通状态使用表面变体色。
- 悬停状态与周围有轻微区别。
- 按下状态使用主题主色的深色版本。
- 高亮按钮保持主色，键盘焦点显示更明显的边框。
- 禁用状态降低背景不透明度。

反馈使用 `down` 状态，因此鼠标和触摸按下都生效，没有依赖桌面端悬停。

## 3. 扩展课程资料

`Course` 新增两个可选字段：

```text
assessmentStandard  期末考核标准，最多 2000 字符
teachingPlan        课程教学安排，最多 5000 字符
```

课程编辑弹窗提供两个多行文本区，可记录成绩构成、考试方式、章节进度、实验、作业和
其他教学节点。字段经过 Domain 校验、Application 用例、Presentation 模型和 SQLite
Repository，不由 QML 直接访问数据库。

## 4. 数据库升级

数据库版本从 4 升级到 5。迁移在 `courses` 表增加：

```text
assessment_standard TEXT NOT NULL DEFAULT ''
teaching_plan       TEXT NOT NULL DEFAULT ''
```

默认空字符串保证已有课程能无损升级。原计划中的任意周次集合迁移顺延为版本 6，避免
复用已经发布的迁移编号。
