# 第四十课：响应式周课表界面

## 本课目标

在现有真实数据链路上完成课表的主要阅读界面。桌面宽窗口使用星期与节次网格，Android
风格窄窗口使用按天分组列表，两种布局消费同一个 `ScheduleViewModel`。

## 1. 桌面周网格

- 横向显示周一至周日。
- 纵向显示第 1～20 节。
- 课程块根据起止节次跨越对应高度。
- 同一时间不应存在已保存冲突；异常数据仍需安全显示。
- 课程颜色配合文字和边框，不单独依赖颜色表达信息。

## 2. 窄窗口按天布局

- 640 像素及以下切换为按天分组列表。
- 没有课程的日期可以折叠或显示简短空状态。
- 不使用悬停、右键和双击。
- 主要按钮和课程项保持触摸友好的最小高度。

## 3. 日期与状态

- 每个星期标题同时显示星期和实际日期。
- 当前日期所在列或分组提供轻量强调。
- 保留学期选择、上一周、下一周和返回当前周。
- 非当前教学周、空周和查询失败具有不同提示。

## 4. 组件拆分

计划新增：

```text
components/WeeklyGrid.qml
components/DayScheduleList.qml
components/CourseMeetingCard.qml
```

布局组件只消费模型角色，不访问 Repository 或重新判断单双周。

## 5. 验证计划

- QML 集成测试实例化正式课表页和真实 ViewModel。
- 检查 640、960、1280 三档布局切换。
- 检查空数据、单日多课程、跨多个节次和周切换。
- 检查 ViewModel 重绑定，保证数据库恢复后页面使用新对象。
- `qmllint`、完整构建和全部 CTest 继续通过。

完成后，第 41 课处理冲突交互细节、课程删除和触摸验收。
