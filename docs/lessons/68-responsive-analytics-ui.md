# 第六十八课：共享数据分析页面响应式重排

## 本课目标

本课完成 UI-3 的最后一个业务页面：重排共享数据分析界面的筛选、摘要、趋势图、分类
排行和账户资金流。分析用例、聚合口径、时区和图表数据契约均保持不变。

## 一、共享分析页面

分析页仍从记账本进入，但页面组件位于独立的 `features/analytics` 模块。它只消费通用
图表序列和排行数据，因此未来饮食、学习等模块可以复用图表组件，而不需要复制记账
业务逻辑。

页面现在遵守统一布局规则：

- 内容最大宽度为 1180 px，并在宽屏居中；
- 手机保留 16 px 边距，桌面保留 24 px 边距；
- 页面说明与返回入口集中在首要操作卡片；
- 手机默认折叠高级筛选，桌面自动展开；
- 360 px 下摘要、趋势图、分类分析和账户资金流全部使用单列；
- 1100 px 以上才并排显示两张趋势图或两张分类图。

## 二、筛选和触摸操作

月份范围以及三种图表类型选择器接入 `AppComboBox`，高度满足 48 px 触摸目标。月份、
账户和分类仍保留原有筛选语义，“不限”仍表示统计全部数据。

窄屏下图表选择器占满卡片宽度，避免右侧固定宽度控件挤压标题。筛选摘要始终显示当前
月份、账户数量、分类数量和时区，即使筛选面板处于折叠状态也能确认统计范围。

## 三、图表窄屏策略

- 趋势图在手机上由 340 px 降为 280 px，减少无效纵向占用。
- 分类排行的名称和金额信息在窄屏分成两行，避免文本相互挤压。
- 环形图在窄屏改为“图表在上、图例在下”，并根据图例数量自动增加高度。
- 收入和支出颜色使用主题状态色，深色模式下不再依赖固定浅色值。
- 修复模型重置瞬间图例索引为负数时产生的无效颜色警告。

## 四、自动验证

`app.analytics_qml` 继续验证空状态、柱状图/折线图/环形图切换、6/12/24 月范围、筛选
摘要、恢复默认、ViewModel 重绑定和返回记账本，并新增：

- 360 px 下首要操作卡片不超过 328 px；
- 手机筛选默认折叠且摘要、趋势、分类区域使用单列；
- 图表选择器和月份范围选择器满足 48 px 触摸高度；
- 960 px 下使用三列摘要；
- 1280 px 下趋势和分类区域使用双列，内容仍不超过 1180 px。
