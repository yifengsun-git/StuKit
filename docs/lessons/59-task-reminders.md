# 第五十九课：可靠的任务到期提醒

## 本课目标

让设置了提醒时间的待完成任务在应用运行期间准时出现提醒，并保证同一次提醒不会因
定时扫描或应用重启而重复弹出。

## 完成内容

- `ScanTaskReminders` 从 Repository 读取任务，筛选提醒时间已到且仍为待完成的任务。
- `ITaskReminderNotifier` 隔离提醒的交付方式；当前实现由 `TasksViewModel` 显示应用内
  提醒卡片，以后可以增加 Windows 或 Android 系统通知适配器。
- `IReminderDeliveryStore` 保存提醒交付记录，扫描时使用“任务 UUID + 提醒 UTC 时间”
  判断是否已经提醒。
- SQLite schema 9 新增 `task_reminder_deliveries` 表和交付时间索引；删除任务时由外键
  级联删除对应记录。
- 应用启动后立即扫描一次，随后每 60 秒扫描一次；提醒卡可以由用户关闭。
- 单元测试覆盖同一个提醒只交付一次，数据库升级测试覆盖 schema 9。

## 为什么要保存交付记录

只在内存里记录“已经提醒”并不可靠：程序重启后内存状态会丢失，同一项任务便会再次
弹出。把交付记录存入 SQLite 后，重启和周期扫描都会得到一致结果。用户修改提醒时间
时会形成新的“任务 UUID + 提醒时间”组合，因此仍能按新时间再提醒一次。

当前版本要求 StuKit 正在运行才能显示应用内提醒。未来接入系统通知时，只需新增实现
`ITaskReminderNotifier` 的平台适配器；任务判断、UTC 时间和去重规则可以原样复用。
