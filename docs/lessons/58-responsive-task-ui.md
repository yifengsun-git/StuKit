# 第五十八课：响应式任务清单界面

## 本课目标

让用户能够从主导航进入待办模块，完成任务创建、编辑、查询、状态流转和删除。

## 完成内容

- 首页和侧边栏增加“待办”入口。
- 顶部统计卡展示待完成、已完成、已逾期和完成率。
- 支持关键字、分类和是否显示归档筛选。
- 任务卡展示分类、优先级、课程、截止时间和逾期状态。
- 编辑弹窗支持标题、说明、分类、优先级、课程、截止时间和提醒时间。
- 完成任务可重新打开或归档；归档任务可恢复；物理删除需要确认。
- 680 像素以下统计和筛选自动改为窄屏布局。

第 61 课已将这里的文本时间输入替换为年、月、日、时、分滚轮选择器。
