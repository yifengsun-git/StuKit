# 第 81 课：规划文档与不可变版本

## 本课目标

- 使用 Markdown 作为用户可读、可编辑的规划载体。
- 在同一界面提供源码编辑和 Qt Markdown 预览。
- 每次保存生成新版本，不覆盖历史。
- 导出 UTF-8 `.md` 文件，保留 Mermaid 代码块。

## 核心设计

`PlanRevision` 保存项目 ID、版本号、Markdown 正文、服务协议、模型名称、
本次引用的资料 ID 和 UTC 创建时间。版本号由应用层在当前项目最新版本基础上
递增。

AI 结果在通过结构和资料引用检查后才自动保存。未通过时，内容只载入编辑区，
由用户修改后手动保存。

## 导出边界

- 使用 `QSaveFile` 原子写入，避免中途失败留下半个文件。
- 默认补齐 `.md` 扩展名。
- 预览不加载 Markdown 中的外部图片。
- Mermaid 作为代码保留，不为桌面端强制引入 WebEngine。

## 验收结果

- 手动保存两次后出现 `v1` 和 `v2`。
- 切换历史版本不改写原版本。
- AI 版本显示服务协议和模型，手动版本显示“手动保存”。
- 导出文件是 UTF-8，Markdown 和 Mermaid 正文保持不变。
