# 第 73 课：快速记账模板与月度分类预算

## 本课目标

这一课继续改进已有记账本，不增加新的首页模块：常用账单可以保存为模板；每个支出
分类可以按月设置预算，并随账单变化实时计算使用进度。

## 快速记账模板

`CreateTransactionViewModel` 最多保存 12 个模板。模板包含收支类型、金额、备注、账户
和分类，不保存日期与时间，因此套用模板后仍使用本次记账的日期。模板存入应用自己的
INI 设置文件；同名模板会覆盖，关联账户或分类失效时会提示重新保存。

模板属于输入偏好，不是财务流水，所以不写入 SQLite；实际账单仍只在用户点击保存后
进入数据库。

## 月度预算的数据结构

schema 11 新增 `monthly_category_budgets`：

- `category_id`：支出分类 UUID；
- `budget_year`、`budget_month`：预算所属月份；
- `limit_cents`：正数整数分；
- 三者组成联合主键，同一分类同一月份只有一个预算；
- 分类删除时预算级联删除。

预算是正式用户数据，因此会跟随 SQLite 备份、恢复和安装升级，不放在 QSettings。

## 分层职责

- `MonthlyBudget` 校验分类、月份和正金额。
- `IMonthlyBudgetRepository` 定义保存、删除和按月查询契约。
- `SqliteMonthlyBudgetRepository` 执行 UPSERT 和真实数据库映射。
- `ManageMonthlyBudgets` 验证只能为未归档支出分类设预算，并按记账时区汇总当月支出。
- `MonthlyBudgetViewModel` 负责金额文本解析、剩余/超支金额、比例和稳定中文错误。
- `AccountingHomePage.qml` 只展示进度和触发保存、删除，不直接计算业务口径或执行 SQL。

## 自动刷新规则

切换月份或时区，新增、修改、删除账单，账户转账产生手续费，以及账户分类资料变化时，
预算 ViewModel 都会重新读取实际数据。收入不会计入预算；转账本金不是消费，只有已经
作为支出流水保存的手续费会计入其支出分类。

## 验收结果

- schema 1～10 数据库可以顺序升级到 schema 11；
- 预算可以保存、覆盖、删除，并在重启后恢复；
- 超支时显示超支金额和超过 100% 的实际比例；
- schema 11 备份验证包含预算表；
- 领域、用例、SQLite Repository、组合根和 QML 自动测试均通过。
