# 第四十三课：自定义周次与安全删除

## 本课目标

让一条上课安排可以选择任意教学周，并为单条安排和整门课程提供需要二次确认的删除
入口。编辑课表时，鼠标经过可编辑方块还会出现轻微阴影，帮助确认即将操作的位置。

## 1. 明确周次集合

`CourseMeeting` 现在持有排序、去重后的 `activeWeeks`。旧的起止周和每周/单双周字段
继续保留，用于兼容已有数据；判断某一周是否上课、周课表查询和冲突检测均以明确
周次集合为准。

排课弹窗提供四个快捷操作：

- 全选：选择学期内全部教学周。
- 清空：取消所有周次，保存前会提示至少选择一周。
- 单周：选择第 1、3、5……周。
- 双周：选择第 2、4、6……周。

快捷操作后仍可逐周勾选，因此可以表达“第 1、2、5、8、12 周”等不规则安排。

## 2. 数据库版本 6

迁移新增：

```text
course_meeting_weeks
  meeting_id
  week_number
```

迁移使用递归查询把原有范围与单双周规则展开到新表。保存安排时，安排主记录与全部
周次在同一个事务中更新；任一步失败都会回滚。删除安排后，其周次通过外键级联删除。

删除课程由 Repository 在事务中执行，数据库触发器会先删除它的全部上课安排，安排
的周次再通过外键级联清理，因此不会留下孤立记录。

## 3. 安全删除

- 编辑已有安排时可以选择“删除安排”，确认框会说明课程资料仍会保留。
- 编辑已有课程时可以选择“删除课程”，确认框会明确提示全部上课安排也会删除。
- 已归档学期仍保持只读，Application 层会拒绝删除请求，而不只依赖按钮禁用。
- 删除成功后重新加载管理页和周课表，避免界面继续显示已删除数据。

## 4. 悬停反馈

编辑模式中的空白网格加入 `HoverHandler`。鼠标进入后显示半透明主色边框和向下偏移的
阴影；离开时用短动画淡出。课程卡片也会在悬停时使用稍深的表面色。这个效果只是
桌面端辅助反馈，点击仍是唯一操作条件，不影响后续 Android 触摸操作。

## 5. 验证

- Domain 测试覆盖任意周次排序、去重和命中判断。
- SQLite 测试覆盖任意周次保存、读取、删除以及课程级联删除。
- 数据库升级测试覆盖版本 6、旧规则展开和备份结构校验。
- QML 集成测试覆盖编辑弹窗默认全选与周次快捷按钮。
- 完整构建、QML 静态检查和全部自动测试通过。
