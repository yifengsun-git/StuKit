# StuKit 待办模块开发计划

## 1. 模块目标

待办模块面向学生的学习任务管理，统一承载普通作业、考试准备和竞赛事项。用户可以
按截止时间和优先级安排任务，设置到期前提醒，完成后归档，并查看完成率。作业可以
选择性绑定课表中的课程，但没有课程的通用待办也必须能独立使用。

模块继续采用 Domain、Application、Infrastructure、Presentation、QML 分层。Windows
第一版完成后，领域规则和用例可直接用于 Android；系统通知只通过平台端口替换。

当前进度：第 53～61 课已完成。任务领域规则、用例、SQLite schema 10、课程查询、
自定义分类、滚轮日期时间选择、响应式页面和可靠的应用内提醒已经接通，进入人工验收。

## 2. 第一版功能范围

### 必须完成

- 新建、编辑和删除任务。
- 标题、说明、截止时间、优先级和自定义分类。
- 初始提供作业、考试、竞赛，用户可以继续添加自己的分类。
- 状态包含待完成、已完成和已归档。
- 支持在截止时间前设置提醒。
- 首页按逾期、今天、近期和无截止时间分组。
- 已完成任务可以归档；归档页可查看和恢复。
- 显示总任务、已完成、逾期和完成率。
- 新建作业时可以选择课表中的某门课程，也可以不绑定。
- 宽窗口和 360 像素窄窗口均可操作。

### 后续增强

- 子任务、重复任务、标签和自定义分类。
- 番茄钟与任务耗时统计。
- 课程结束后自动整理相关任务。
- 日历视图、系统日历同步和云同步。
- 跨设备推送提醒。

## 3. 核心领域模型

### `TaskItem`

保存任务 UUID、标题、说明、截止 UTC 时间、提醒 UTC 时间、优先级、分类、状态、
完成 UTC 时间、创建 UTC 时间，以及可选课程引用。

核心规则：

- 标题去除首尾空白后不能为空，最长 120 字符。
- 说明最长 5000 字符。
- 所有持久化时间统一为 UTC；显示时转换到用户时区。
- 提醒必须依附截止时间，且不能晚于截止时间。
- 已完成和已归档状态必须有完成时间；待完成状态不能伪带完成时间。
- 已归档只表示完成任务离开主清单，不等同于物理删除。

### 优先级与分类

- 优先级：低、普通、高、紧急。
- 分类：作业、考试、竞赛。

这些值使用稳定枚举写入数据库，QML 只使用 Presentation 提供的可读文本和颜色，不
直接解释数据库数字。

## 4. 与课表的联动边界

待办 Domain 不包含也不引用 `schedule::Course`。任务只保存：

- 可选 `courseId`，用于继续查询课程；
- `courseNameSnapshot`，用于课程改名或删除后仍能解释历史任务。

Application 定义只读的 `ICourseLookup` 端口，组合根再用课表 Repository 实现适配器。
这样待办模块可以单独测试，课表也不会反向依赖待办。任务表不对课程表建立数据库外键，
避免删除课程时意外删除作业历史。

## 5. 提醒策略

第一版提醒由 Application 产生“当前需要提醒的任务”，平台适配器负责交付：

```text
任务与提醒规则 -> ReminderScheduler 端口 -> Windows 通知适配器
                                      -> Android 通知适配器（后续）
```

提醒时间和截止时间存 UTC。应用启动、任务保存和定时扫描时重新安排提醒，避免只把
定时器留在内存中。未取得系统通知能力时，至少在应用内显示到期提醒，不静默丢失。

## 6. 数据与统计

SQLite 继续使用 StuKit 共享数据库，通过新迁移创建 `tasks` 表和必要索引。Repository
支持状态、时间范围、分类和课程过滤。物理删除只用于用户明确删除；完成和归档都是
可恢复的状态变更。

默认完成率口径：

```text
已完成数量 /（待完成数量 + 已完成数量）
```

归档但曾完成的任务计入已完成；统计可按最近 7 天、30 天、学期、分类或课程扩展。
无任务时完成率显示为 `0%`，不产生除零或误导性的 `100%`。

## 7. 目录结构

```text
src/features/tasks/
  domain/          TaskItem、枚举、Repository 契约
  application/     保存、查询、完成、归档、统计、提醒和课程查询端口
  infrastructure/  SQLite Repository、课程查询与平台提醒适配器
  presentation/    TasksViewModel 与列表模型
  qml/             任务首页、编辑器、归档与统计界面
```

依赖方向保持：

```text
QML -> Presentation -> Application -> Domain
Infrastructure --------------------------> Application + Domain
```

## 9. 完成标准

- 可以完整执行创建、编辑、完成、归档、恢复和删除任务。
- 截止时间、提醒、逾期状态在自定义时区下显示正确。
- 作业可绑定真实课程，课程变化后历史名称仍可读。
- 完成率口径固定且有自动化测试。
- 应用重启后任务与提醒设置不丢失。
- Windows Debug 构建、QML 静态检查和全部自动化测试通过。
